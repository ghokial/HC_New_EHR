# Geographic data attribution

Country, state/province, and city data are derived from the community-maintained [Countries States Cities Database](https://github.com/dr5hn/countries-states-cities-database), licensed under the Open Database License 1.0 (ODbL-1.0).

Run `node scripts/build-geography-assets.mjs` after downloading the release file `json-countries+states+cities.json.gz` to the project root as `tmp-world-geography.json.gz`.
